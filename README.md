# EdTech Pantheon

교육공학의 사상을 **36명의 인물, 54개의 관계, 108개의 연표 사건, 123개의 출처**로 읽는 한국어 공개 시각 아카이브입니다. 인물별 핵심 주장뿐 아니라 주요 저작, 지적 계보, 개념적 대비와 그 근거를 함께 탐색할 수 있습니다.

**Live site:** https://taehyeonglim.github.io/edtech-pantheon/

## 편집 및 근거 모델

콘텐츠는 `src/data/pioneers.ts`, `src/data/relationships.ts`, `src/data/sources.ts`와 각 확장 데이터 모듈에 구조화되어 있습니다. 핵심 주장, 저작, 연표 사건과 관계는 `sourceIds`를 통해 출처 레코드를 참조합니다.

출처 등급은 다음과 같습니다.

- **A** — 원저작, 당사자 기록, 원문 아카이브
- **B** — 동료평가 연구, 학술 자료, 대학·학회·전문기관 기록
- **C** — 탐색과 교차 확인을 위한 백과·일반 참고 자료

등급은 자료의 품질을 기계적으로 확정하는 점수가 아닙니다. 특히 직접 영향, 공동 연구, 저작 연도와 생애 사실은 가능한 한 해당 주장을 직접 뒷받침하는 A·B 등급 자료로 확인해야 합니다. 사이트의 문장은 직접 인용문이 아니라 연결된 출처를 바탕으로 작성한 편집 요약을 원칙으로 합니다.

## 알려진 검수 이슈

검수 통과는 콘텐츠가 모두 최종 확정되었다는 뜻이 아닙니다. 현재 우선순위는 다음과 같습니다.

### P1 — 공개 신뢰도에 직접 영향을 주는 항목

1. **Ann L. Brown과 John Seely Brown의 혼동**

   `brown-collins` 관계가 Ann L. Brown과 Allan Collins가 인지적 도제를 공동 개발한 것으로 서술되어 있습니다. 해당 저작의 실제 저자는 Allan Collins, John Seely Brown, Susan Newman이므로 관계를 삭제하거나 Ann Brown–Collins의 설계연구 비교로 다시 근거화해야 합니다.

2. **관계 근거의 추적성 부족**

   관계 상세 화면은 `gagne-1985` 같은 내부 출처 ID만 표시하며 원문 링크로 이동할 수 없습니다. 방법론이 약속하는 페이지·DOI·접근일 메타데이터도 현재 데이터 타입에 완전히 반영되어 있지 않습니다.

3. **초상 이미지 권리 미확정**

   36개 초상 중 14개만 명확한 퍼블릭 도메인 또는 CC 근거가 확인됐습니다. 나머지 22개는 권리 상태가 불명확하거나 별도 허가가 필요하며, Rita Richey 초상은 `In Copyright`로 표시됩니다. 확인 전에는 이니셜 대체 이미지를 사용하는 것이 안전합니다.

4. **서지·연표의 직접 근거 보강**

   Richard Mayer 논문의 로컬 연도 표기는 DOI 메타데이터와 다르고, John Keller 저작명 일부가 원문 제목과 일치하지 않습니다. Bloom, Gagné, Bruner, Merrill, Keller, Papert의 일부 연표 사건은 사건 자체보다 오래된 자료만 연결되어 있어 해당 저작 또는 사건의 직접 출처가 필요합니다.

5. **전기 자료의 C 등급 의존**

   다수 인물의 생애 서술이 Wikipedia 등 C 등급 자료에 의존합니다. 대학 아카이브, 학회 기록, 부고, 당사자 이력 등 A·B 등급 전거로 교체하거나 교차 확인해야 합니다.

### P2 — 사용성·접근성·운영 품질

- 640px 이하 헤더에서 `비교실`과 `방법론` 링크가 숨겨져 전역 탐색 경로가 불완전합니다.
- 인물 목록의 `측정` 필터가 부분 문자열 비교 때문에 `교육측정`까지 포함합니다.
- 일부 보조 텍스트와 골드 계열 텍스트의 명암비가 WCAG AA 4.5:1에 미달하고 8—11px 크기의 라벨이 많습니다.
- 홈 캐러셀은 정지·화면 밖·감소된 모션 환경에서도 36개 카드를 계속 렌더링할 수 있습니다.
- 초상 폴더는 약 7.6MB이며 Jean Lave 이미지는 약 2.6MB입니다. 고정 크기, `srcset`, WebP/AVIF 변환이 필요합니다.
- 인물 상세의 Evidence Index가 고유 출처가 아닌 중복 인용 횟수를 표시하고 일부 저작·연표 출처를 집계하지 않습니다.
- `robots.txt`가 가리키는 `sitemap-index.xml`이 생성되지 않으며 canonical, Open Graph, Twitter Card 메타데이터가 없습니다.

### P3 — 유지보수

- 핵심 사용자 동선을 보호하는 자동화 테스트가 없습니다.
- 프로젝트 전체 `html-validate` 기준선이 없어 기존 위반과 새 회귀를 분리하기 어렵습니다.
- `@xyflow/react` 의존성과 `apa-ethics` 출처 레코드는 현재 사용되지 않습니다.
- 일부 한국어 음역과 생존 인물의 연도 표기 방식이 일관되지 않습니다.
- 비교표 HTML 생성은 현재 로컬의 신뢰된 데이터만 사용하지만, 향후 외부 입력을 받을 경우 문자열 이스케이프가 필요합니다.

## 로컬 개발

Node.js와 npm이 필요합니다.

```bash
npm install
npm run dev
```

기본 개발 서버가 표시하는 URL에서 프로젝트를 확인합니다. GitHub Pages 하위 경로 배포를 위해 Astro의 base path 설정을 유지해야 합니다.

## 검증 명령

변경 사항을 제출하기 전에 최소한 다음 명령을 실행합니다.

```bash
npm run check
npm run build
npm audit
npx --yes html-validate@10.8.0 'dist/**/*.html'
```

콘텐츠를 변경한 경우에는 빌드 성공만으로 충분하지 않습니다. 해당 문장과 사건의 출처 링크가 실제 주장을 직접 뒷받침하는지, 초상 파일의 재배포 권리가 명시되어 있는지, 데스크톱과 모바일에서 변경된 동선을 직접 확인해야 합니다.

## 저장소 구조

```text
src/
├── components/      # 캐러셀, 관계도, 인용·카드 UI
├── data/            # 인물, 전기, 관계, 연표, 출처, 초상 메타데이터
├── layouts/         # 공통 HTML 레이아웃
├── pages/           # Astro 라우트
└── styles/          # 전역 디자인 시스템과 반응형 규칙
public/
├── portraits/       # 초상 이미지 파일
├── brand-mark.png   # 헤더와 favicon에 사용하는 투명 로고
├── favicon.svg
└── robots.txt
```
